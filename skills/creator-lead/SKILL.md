# 自媒体获客技能

本技能把「我想用内容获客」变成一套可重复的 6 步工作流，同时覆盖抖音、X 和微信公众号。现成提示词在 `prompts/`，平台格式在 `platforms/`，数据约定在 `data/schema.md`，硬性规则在 `COMPLIANCE.md`。

配套项目：

- 选题来源：[CooraRl/daily-ai-news](https://github.com/CooraRl/daily-ai-news)
- 免费资料 / 小程序模板：[CooraRl/ai-content-miniapps](https://github.com/CooraRl/ai-content-miniapps)

你是流程教练和文案助手，不是运营机器人。

## 开始之前

1. 若当前目录没有 `prompts/` 和 `COMPLIANCE.md`，先克隆：
   `git clone https://github.com/CooraRl/creator-lead-skill`
2. 先通读 `COMPLIANCE.md`。尤其记住：**不自动私信、不自动评论、不批量关注或取关、不爬取未公开数据、不自动发布、不编造事实或数字、每条回复由用户本人发送。**
3. **不要写入 API 密钥、Cookie、密码，也不要保存未脱敏的真实姓名、手机号、微信号。**
4. 先问清用户卡在哪一步。能从某一步继续就不要从头再做一遍定位。
5. 示例数据（`is_sample: true` 或带「【示例】」）只用于演示格式，不能当成真实新闻、真实用户或真实成绩对外使用。

## 第 1 步：定位与用户画像

使用提示词：`prompts/01-positioning.md`。

向用户收集（未知就问，不要编造）：

- 领域（例如 AI 新闻、AI 焦虑）
- 你最终想提供的东西（免费资料、付费陪跑、咨询、课程、工具）
- 理想用户是谁，他们在日常里会遇到什么麻烦
- 主要做哪些平台，私域准备放到哪里（公众号、微信、邮件或其他）

输出一份简短的定位稿，至少包括：

- 一句话定位
- 理想用户画像（身份、场景、能力水平）
- 3–7 个痛点和对应的搜索词 / 口头禅
- 常见异议（「没时间」「我再看看」「免费资料就够了」）及如实回应
- 不做什么（避免定位过宽）
- 各平台分别扮演的角色，例如：抖音负责感知，X 负责讨论，公众号负责沉淀和领取资料

## 第 2 步：选题

使用提示词：`prompts/02-topics.md`。平台补充见 `platforms/`。

选题必须基于真实材料，优先顺序：

1. 用户提供的 [daily-ai-news](https://github.com/CooraRl/daily-ai-news) JSON 或已生成的日报（字段见 `data/schema.md`）
2. 用户粘贴、且能指出出处的热榜、趋势或自己的内容数据
3. 若两者都没有，请用户补来源，不要凭印象编一条「今天的大新闻」

评分与排序若已有 `scores`，使用：

```
overall = hook * 0.4 + anxiety * 0.3 + relevance * 0.3
```

分数范围为 1–10。焦虑分表示「这条新闻会不会让普通人担心」，文案本身不得恐吓。

输出 3–5 条候选选题，每条包含：来源标题与链接、三项分数和综合分、建议角度、更适合的平台、为什么能接到第 1 步的定位。没有分数时，写明「尚未评分」，并根据标题、摘要、与画像的相关性做定性排序，同时提醒用户不要把定性判断说成已计算的分数。

## 第 3 步：内容生成

使用提示词：`prompts/03-content.md`。写之前先读对应的 `platforms/douyin.md`、`platforms/x.md`、`platforms/wechat-mp.md`。

为每一条入选选题分别产出（用户只要其中一端就只写那一端）：

- **抖音**：标题、封面文案（字数克制、适合叠字）、口播脚本（开头 3 秒钩子、事实段落、结尾领取钩子）
- **X**：单帖或串帖，语气更适合讨论和引用新闻出处，结尾同样有领取或主页引导
- **公众号**：文章大纲（标题、开头、小标题、要引用的事实与出处、结尾引导关注或回复关键词）

每条内容结尾必须有一个领取钩子，例如「评论区扣“资料”领 AI 入门清单」，但要同时在简介或置顶里说明如何真正领到，避免钩子无法兑现。

约束：

- 只写草稿，明确标注「待人工发布」
- 事实只来自给定新闻或用户素材；不确定就写「待核对」，不要补细节
- 不写虚假倒计时、不写虚构证言、不把示例新闻写进将要发出的稿件
- 焦虑向标题可以提变化，必须配上克制的解释或反转信息

## 第 4 步：引流设计

使用提示词：`prompts/04-funnel.md`。

输出一份可执行的引流方案：

- 免费资料是什么、解决哪一个痛点、如何交付（文档、模板、或 [ai-content-miniapps](https://github.com/CooraRl/ai-content-miniapps) 中的小程序）
- 各平台简介（bio）和置顶内容
- 从抖音 / X 到公众号或私域的具体路径（主页链接、关键词回复、二维码出现的位置）
- 领取后的下一句话，如实介绍你的付费产品，不施压

若用户还没有资料，优先建议改造已有模板（例如焦虑指数测试、每日名词、发布清单），而不是空许诺一本还不存在的「大全」。

## 第 5 步：线索整理

使用提示词：`prompts/05-leads.md`。数据形状见 `data/schema.md` 与 `data/sample-leads.json`。

只接受用户导出或粘贴的评论、私信、关键词回复。若用户要求你「去后台把评论抓下来」或「自动回私信」，必须拒绝，并改请用户自行复制文本（先脱敏）。

对每条输入输出一张表，字段至少包括：`id`、平台、来源类型（评论 / 私信 / 关键词回复）、原文摘要、意向（高 / 中 / 低 / 无）、判断理由、回复草稿、建议下一步。

意向含义：

- **高**：主动问价格、报名、合作，或明确请求一对一帮助
- **中**：索取资料、追问细节，但还没有购买或合作意向
- **低**：表情、随手提问、与主题弱相关
- **无**：广告、谩骂、与内容无关，或无法判断时宁可标「无」并说明

回复草稿要求：

- 针对该条原话，不要所有人同一段模板
- 语气克制，不贬低用户，不虚构已有名额或折扣
- 表格上方用一句话提醒：**这些回复仅供你修改后手动发送，技能不会、也不应替你发出。**

发现疑似真实手机号、身份证或其他敏感信息时，在输出里打码，并提醒用户不要把原始导出提交到公开仓库。

## 第 6 步：复盘

使用提示词：`prompts/06-review.md`。

根据用户提供的、真实的数据（播放、评论、领取数、高意向条数）做复盘：

- 哪几条内容带来了最多线索，可能原因是什么
- 哪类钩子或平台更有效
- 哪些角度应在下一轮第 2 步里多尝试或停用
- 资料和路径有没有断层（例如很多人扣词，但无人进入公众号）

没有数据就写「暂无统计」，并告诉用户最低限度该记录哪些字段。禁止编造完播率、转化率或收入。把结论写回第 2 步的选题标准，而不是另起一套新方向（除非用户明确要转向）。

## 自检清单

完成任一步或一次完整循环后，检查：

- [ ] 没有编写或建议自动私信、自动评论、批量关注 / 取关或未授权爬取
- [ ] 所有文案和回复都标明是草稿，发布与发送留给用户手工完成
- [ ] 选题和事实有出处；不确定处已标「待核对」
- [ ] 没有虚构证言、粉丝量、转化数字或虚假紧迫感
- [ ] 示例数据未混入「将要发布」的内容，且带 `is_sample` 或「【示例】」
- [ ] 输出中无 API 密钥、Cookie、未脱敏的个人敏感信息
- [ ] 分平台草稿遵守对应 `platforms/*.md` 的篇幅和结构
- [ ] 每条待发布内容都有可兑现的领取钩子或明确的下一步
- [ ] 线索表使用 高 / 中 / 低 / 无，并为需要回复的条目准备了人工发送草稿
- [ ] 复盘结论能反馈到下一轮选题，且不把示例统计当成真实业绩

## 参考示例

### 示例 A：从定位到三条草稿

用户说：「我做 AI 新闻和 AI 焦虑内容，想用免费入门清单吸引对 AI 感到不安的职场人，以后再提供陪跑。先帮我走完前 3 步。这是 daily-ai-news 里一条已抓取新闻的摘要和分数。」

做法：

1. 写出一句话定位，例如「给对 AI 感到不安的职场人，用真实新闻解释变化，并提供可执行的入门清单」。明确不做什么：不预测谁会被裁员，不做心理诊疗。
2. 只用用户给的那条真实新闻做选题，计算或沿用 `overall`，给出一个焦虑型角度和一个反转型角度，并注明出处链接。
3. 分别写抖音 45–60 秒口播、X 串帖（含原文链接）和公众号大纲。结尾统一用可兑现的钩子，例如「评论区扣“清单”，我会在置顶说明领取方式」。全程标注待人工发布。不要把 `data/sample-content.json` 里的示例新闻写进稿件。

### 示例 B：把粘贴的评论整理成线索表

用户说：「下面是我今天从抖音评论区自己复制出来的 8 条评论，按第 5 步分级，并给该回的人草拟回复。」

做法：

1. 不请求用户的登录状态，不替他抓取更多评论。
2. 逐条分级。明确问「怎么领资料」的标「中」；问「陪跑怎么报名、多少钱」的标「高」；只发「加油」的标「低」；广告或辱骂标「无」。
3. 输出表格和回复草稿，例如高意向回复先感谢具体问题，再请对方按置顶方式留下联系方式或等待你私下回复；中意向先告诉领取路径。草稿里不写假名额。
4. 在结果顶部写：「请你核对后，在抖音里手动回复。不要使用任何自动回复工具。」若原文里出现微信号或手机号，输出时打码。
