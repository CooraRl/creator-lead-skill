# 抖音（Douyin）格式与合规要点

本页只说明怎么写草稿和怎么人工运营。不提供自动发布、自动评论、自动私信或刷量的方法。

## 内容形态

- **时长**：优先 15–60 秒口播；需要把新闻讲清楚时可以到 1–3 分钟，但前 3 秒必须给出钩子。
- **口播字数**：按每秒约 4–6 个汉字估算。60 秒稿大约 250–350 字，不要写成文章再硬念。
- **标题**：建议 12–20 字，信息具体，避免纯情绪词堆砌。可同时准备焦虑型和反转型各一条，供用户选择。
- **封面文案**：4–10 个字为佳，适合大字叠在封面上。不要把整段标题搬上封面，也不要在画面里堆许多小字。
- **正文 / 简介**：补充出处、资料名称和领取方式。关键信息不要只藏在口播里。
- **话题标签**：少量、相关即可，不要堆无关热词。

## 结构建议

1. 开头 3 秒：提出一个真实变化或一个具体问题（必须能被后文的事实支撑）。
2. 中间：用新闻里已经有的信息说明「发生了什么」「和普通使用者有什么关系」。口播中提及出处（媒体或官网名称），完整链接放简介。
3. 结尾 CTA：给出一个可兑现的领取钩子，例如「想要入门清单的，评论区扣“清单”，领取方式写在置顶」。
4. 置顶评论或置顶视频中必须出现真正的领取步骤，否则不要用「扣词领取」这个钩子。

## CTA 写法

推荐：评论区关键词 + 置顶说明、主页简介里的公众号引导、置顶视频里演示如何领取。

不推荐：要求观众在公开评论区留下手机号或微信号；承诺「评论即私信发送」却打算用机器人群发；虚假限时。

## 合规要点

- 遵守抖音社区公约与广告相关规则。教育培训、金融、医疗等需要资质的内容不要用本技能绕过审核。
- 禁止自动评论、自动私信、批量关注或取关、买量刷互动。
- 不要使用误导性「AI 合成真实新闻现场」而不说明；引用新闻时不歪曲原意。
- 涉及职业与焦虑时，明确这不是裁员预测或心理诊断。
- 所有稿件状态为草稿，由用户在抖音 App 或官方创作者工具中手动发布。
